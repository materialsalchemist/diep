## Changelog

### 2.0.0 - 2026-10-20

* The new version of `diep`: a standalone PyTorch Geometric implementation with no DGL or
  matgl dependency, plus `diep_fold1`, a pretrained potential trained on MatPES r2SCAN, and
  the code that trained, exported and evaluated it. See `README.md` and `diep/README.md`.
* The 0.x modules, DGL backend and `diep` CLI are removed from the package. The 0.x code is kept unchanged in `legacy/`.

### 0.1.1 - 2024-11-22

* Fixes.

### 0.1.0 - 2024-11-22

* The pre-release version 0.1.0 based on the Matgl code-base.
